Quick answers

A protected PDF or Excel file will not open

Type the file’s password in the File password box on the Statements page, then upload. The password is used only to open the file and is never saved. If you upload several files at once they must share one password, so upload files with different passwords separately.

It says the totals do not balance

The opening balance plus credits minus debits should equal the closing balance. If it does not, some rows were misread. Try the Excel version of the statement instead of the PDF, or contact us with the month and file type.

Many payments are “Uncategorised”

These payments have a name or number but no keyword such as Tithe or Offering. Choose the right category from the dropdown beside each one. To catch them automatically next time, add the word under Categories, then open the statement and press Re-run rules.

Uploading a big statement takes a long time

A full year can take around a minute. Keep the page open until it finishes.

The annual report is missing expenses

The report is built from bank transactions. Cash withdrawals and cheques need a category, and items that never touch the bank, such as depreciation, are added as manual report entries in Admin.

How do I install the app on my phone?

Press Install app at the top of the page. On an iPhone, tap Share, then Add to Home Screen.
